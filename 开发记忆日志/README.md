## 📌 核心维护原则

1. **防臃肿原则**：
   - 严禁向 Git 仓库直接提交大体积二进制安装包（APK）或打包源码（Zip/7z/Tar）。
   - APK 软件分发统一使用 **网盘分享** 或 **GitHub Releases** 附件。
2. **零死链原则**：
   - 任何配置文件的删除或重命名，必须同步检查并更新 `README.md`、`tv8.json`、`自用仓库.txt` 中的引用链接。
3. **JAR 生命周期管理**：
   - 当引入新版本的 Spider JAR 时，必须同步淘汰并删除被替代的旧版本 JAR，禁止长期堆积历史无用包。
4. **UTF-8 字符编码规范**：
   - 所有 JSON 与 TXT 配置文件均保持无 BOM 的 UTF-8 编码，防止中文路径在跨平台或代理访问时乱码。
