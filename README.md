## 💡 常见问题与观影优化

<details>
<summary><b>Q1: 播放时遇到卡顿或提示解码失败怎么办？</b></summary>
答：进入播放界面或全局设置中，将「默认解码器」从系统自带切换为 <b>ijk硬解</b> 或 <b>EXO</b>，对于高规格 4K 原画片源，ijk 硬解通常更稳定省电。
</details>

<details>
<summary><b>Q2: 4K 原画网盘源（阿里/夸克/UC）提示需要扫码？</b></summary>
答：网盘类站源为保证 4K 无损码率播放，需要挂载个人网盘账号（免费版即可）。只需按电视屏幕提示用对应手机 App 扫码授权一次，之后即可终身享受免限速 4K 原画秒播！
</details>

<details>
<summary><b>Q3: 电视提示“无法下载配置”或“超时”？</b></summary>
答：部分老旧路由或运营商 DNS 可能偶发拦截，请尝试将接口前缀切换为备用 ghproxy 线路：<br>
<code>https://ghproxy.net/https://raw.githubusercontent.com/niubihu1/tvbox/main/1.json</code>
</details>
